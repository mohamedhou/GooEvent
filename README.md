# 🎟️ GooEvent – Application Web de Billetterie d'Événements

## 📌 Description
**GooEvent** est une plateforme de gestion d’événements permettant la création, la publication et la vente de billets en ligne. L’application offre aux organisateurs une interface intuitive pour gérer les événements, et aux participants la possibilité de réserver et de recevoir des billets numériques.

## 🛠️ Technologies utilisées
- **WebDev** / WinDev
- **CSS**, HTML
- **HFSQL**
- Méthodologie Agile (Scrum)

## 🔍 Fonctionnalités principales
- Création et modification d’événements
- Génération automatique de billets numériques avec QR Code
- Réservation en ligne
- Tableau de bord des ventes
- Intégration avec l’application mobile de scan `App_Scan_GOOEvent`
